
# Multi-Domain Intelligence Platform

## Quick Start
1. Install: `pip install -r requirements.txt`
2. Run: `streamlit run Home.py`

## OOP Architecture
This project uses Object-Oriented Programming:
- **Models**: `SecurityIncident` class in `models/`
- **Services**: `DatabaseManager` class in `services/`
- **Legacy**: Existing CRUD functions in `app/data/`

## 📊 Features
✅ **Three Working Dashboards**: Cybersecurity, Data Science, IT Operations  
✅ **AI Integration**: Google Gemini for analysis and chat  
✅ **Authentication**: Secure login with bcrypt hashing  
✅ **Database**: SQLite with full CRUD operations  
✅ **Visualizations**: Multiple interactive charts  
✅ **OOP Implementation**: SecurityIncident model + DatabaseManager service
